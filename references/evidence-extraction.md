# Decision-Relevant Evidence Extraction

## Read by Target, Not by Paper

Define the required information before opening full texts. Typical targets include:

- preparation, intervention, or data-acquisition method;
- settings and parameters necessary for replication;
- minimum check that the intended input or intermediate state exists;
- decisive readout and measurement procedure;
- comparator and controls;
- reported success range, failure boundary, or benchmark;
- figure and caption that show the representative outcome;
- limitations and common failure modes.

Ignore sections that do not affect the current zero-to-one decision. They remain available for later one-to-ten work.

## Use an Evidence File

Create a file or table analogous to a validation notebook. Place each source under a traceable heading and capture only the target evidence.

Recommended fields:

| Field | Content |
|---|---|
| Source ID | Citation key, DOI, PMID, URL, or library identifier |
| Evidence target | Method, readout, control, threshold, or failure mode |
| Extract | Short quotation, paraphrase, screenshot, figure, or table |
| Location | Section, page, figure, table, or supplement |
| Conditions | Material, population, model, instrument, software, or settings |
| Outcome | What happened and at what scale |
| Relevance | How it changes the pilot |
| Caveat | Missing details, bias, incompatibility, or uncertainty |

Preserve figure captions with screenshots. Keep the source identifier close to every extracted item.

## Batch Similar Work

To reduce context switching:

1. Export or list source metadata first.
2. Create source headings in one pass.
3. Locate methods across all selected papers.
4. Capture representative outcomes across all papers.
5. Extract controls and thresholds.
6. Compare evidence only after capture is sufficiently complete.

Do not stop to normalize fonts, layouts, or minor formatting while collecting evidence.

## Use Minimum Characterization

Choose the least expensive or complex observation that confirms the required state. If one microscopy scale, assay, diagnostic plot, or validation metric can distinguish the target, begin there. Add other methods only when they resolve an identified ambiguity.

Minimum does not mean careless. It means every measurement has a decision role.

## Compare Across Sources

After extraction, build a comparison matrix:

| Source | Method route | Critical parameters | Verification | Decisive result | Controls | Caveats |
|---|---|---|---|---|---|---|

Look for:

- consensus and recurring ranges;
- parameter choices that explain divergent outcomes;
- methods that appear robust across conditions;
- hidden dependencies in supplements;
- selective presentation or missing negative evidence;
- routes that fit available resources and constraints.

Use multiple sources to avoid inheriting an error or unsuitable setting from a single paper.
